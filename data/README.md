# Film data

Everything that is specific to a film: the transcribed cards with their timecodes, the
translations, the per-film card style, the designers' finished cards, and fonts. This is
the part volunteers and designers touch. It never contains a print.

```
films/<slug>/film.yaml        metadata, rights note, the reference print (source + hash), frame size
films/<slug>/cards.yaml       the cards (source of truth); schema in films/_example/cards.yaml
films/<slug>/style.css        the automatic card's look for this film
films/<slug>/cards/<lang>/    hand-made cards, one PNG per card id
locales/templates/<slug>.pot  generated by the pipeline; what Crowdin reads
locales/<lang>/<slug>.po      translations, written back by Crowdin
fonts/                        OFL fonts referenced from style.css
```

Languages use Crowdin locale codes (`es-MX`). `in`/`out` are optional until the film is timed; text and order are enough for translation. Card ids are stable forever; insert later
cards as `042a`, never renumber. Guidelines for contributors: `docs/translating.md`,
`docs/designing.md`. `_example` is a fixture used by the pipeline tests.
