THE INTERTITLE PROJECT
Bilingual title cards for silent films
What is this?
Silent films talk with title cards. We are translating those cards into Spanish (Mexican Spanish first) and putting both languages on the same card, so a mixed audience can watch one print together. The film's running time does not change, which means the organist's cues still work.

Translations are done by volunteers. Finished cards are made by designers, or generated automatically when nobody has time to draw them. Then the cards are cut back into the film.

How to help
  • Translate. If you read English and write Spanish, you can translate title cards in your browser. No software to install. Crowdin project (link coming when the strings are ready).
  • Design. If you letter, set type, or draw, you can turn translations into finished cards. See the designer notes.
  • Transcribe. Someone has to type out the original English cards from the print. It is tedious and it matters.
  • Bring a film. Any silent film in the public domain can go through the same pipeline.
The rules of the road
1. The translation has to be as short as the English. The card is on screen for a fixed number of seconds.
2. Jokes have to land in Spanish, not just translate.
3. Names stay. Harold is Harold.
4. Everything we make is free for any theatre to use, with credit.
